# Сеть и порты сервера

Порты по умолчанию: **UDP — 9090**, **TCP — 8080**, **WebSocket — 1010**. Все три протокола включены по умолчанию.

Убедитесь, что клиент может подключиться к нужным портам. Проверьте правила файрвола на сервере и у провайдера.

## Изменить протокол или порт

Включённые протоколы и порты настраиваются в `/etc/tungo/server_configuration.json`. При изменении порта сервера обновите его и в конфигурациях клиентов. После изменений перезапустите сервер и клиенты.
