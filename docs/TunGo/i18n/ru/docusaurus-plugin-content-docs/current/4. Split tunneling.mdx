# Раздельное туннелирование

`TunnelRoutesV4` и `TunnelRoutesV6` — поля верхнего уровня клиентской конфигурации, содержащие подсети назначения в формате CIDR. Трафик к этим подсетям направляется через VPN; для остальных адресов используются другие системные маршруты. Эти поля не ограничивают адреса источника пакетов.

Например, чтобы направить трафик к двум подсетям через VPN:

```json
{
  "TunnelRoutesV4": ["192.0.2.0/24"],
  "TunnelRoutesV6": ["2001:db8::/64"]
}
```

## Поведение по умолчанию

Отсутствующее поле или `null` включает полный туннель для соответствующего семейства адресов. Пустой массив не добавляет маршруты из этого списка. Маршруты к подсети VPN и настроенным DNS-серверам применяются в любом случае. Некорректные CIDR также заменяются маршрутами полного туннеля с предупреждением в логе клиента.
