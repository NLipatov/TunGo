# 拆分隧道

`TunnelRoutesV4` 和 `TunnelRoutesV6` 是客户端配置中的顶层字段，用于指定以 CIDR 表示的目标子网。发往这些子网的流量通过 VPN 路由；其他目标使用系统中其余的路由。这些字段不限制数据包的源地址。

例如，要将发往两个目标子网的流量通过 VPN 路由，可使用以下配置：

```json
{
  "TunnelRoutesV4": ["192.0.2.0/24"],
  "TunnelRoutesV6": ["2001:db8::/64"]
}
```

## 默认行为

省略字段或将其设为 `null` 时，对应地址族会使用全隧道默认路由。空数组不会从该列表添加任何路由。通往 VPN 子网和已配置 DNS 服务器的路由仍然生效。无效的 CIDR 也会被替换为全隧道默认路由，并在客户端日志中产生警告。
