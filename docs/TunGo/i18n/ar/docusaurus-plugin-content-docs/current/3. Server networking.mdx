# شبكة الخادم ومنافذه

المنافذ الافتراضية: **UDP: 9090** و**TCP: 8080** و**WebSocket: 1010**. البروتوكولات الثلاثة مفعّلة افتراضيًا.

تأكد من أن العميل يستطيع الوصول إلى المنافذ المستخدمة، وأن قواعد جدار الحماية على الخادم ولدى مزوّد الخدمة تسمح بهذه الاتصالات.

## تغيير البروتوكول أو المنفذ

تُضبط البروتوكولات المفعّلة والمنافذ في `/etc/tungo/server_configuration.json`. عند تغيير منفذ الخادم، حدّثه أيضًا في إعدادات العملاء. ثم أعد تشغيل الخادم والعملاء.
