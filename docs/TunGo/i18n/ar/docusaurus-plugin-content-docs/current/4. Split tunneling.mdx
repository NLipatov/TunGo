# الأنفاق المقسمة

`TunnelRoutesV4` و`TunnelRoutesV6` حقلان في المستوى الأعلى من إعدادات العميل، ويحتويان على الشبكات الفرعية الوجهة بصيغة CIDR. تُوجَّه حركة المرور إلى هذه الشبكات عبر VPN، بينما تستخدم الوجهات الأخرى مسارات النظام المتبقية. لا يقيّد هذان الحقلان عناوين مصدر الحزم.

على سبيل المثال، لتوجيه حركة المرور إلى شبكتين فرعيتين عبر VPN:

```json
{
  "TunnelRoutesV4": ["192.0.2.0/24"],
  "TunnelRoutesV6": ["2001:db8::/64"]
}
```

## السلوك الافتراضي

عند حذف الحقل أو تعيينه إلى `null`، تُطبَّق مسارات النفق الكامل الافتراضية لعائلة العناوين المعنية. لا تضيف المصفوفة الفارغة أي مسارات من تلك القائمة. تظل المسارات إلى شبكة VPN الفرعية وخوادم DNS المحددة في الإعدادات سارية. كذلك تُستبدل قيم CIDR غير الصالحة بمسارات النفق الكامل، مع تحذير في سجل العميل.
