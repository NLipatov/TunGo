# インストール

クライアントは **Linux、macOS、Windows** で動作します。<br />
サーバーは **Linux でのみ**動作します。

<Tabs>
<TabItem value="linux" label="Linux" default>

<Tabs>
<TabItem value="amd64" label="amd64" default>

```bash
curl -fL -o tungo https://github.com/NLipatov/TunGo/releases/latest/download/tungo-linux-amd64 && \
sudo install -o root -g root -m 0755 tungo /usr/local/bin/tungo
```

</TabItem>
<TabItem value="arm64" label="arm64">

```bash
curl -fL -o tungo https://github.com/NLipatov/TunGo/releases/latest/download/tungo-linux-arm64 && \
sudo install -o root -g root -m 0755 tungo /usr/local/bin/tungo
```

</TabItem>
</Tabs>

</TabItem>
<TabItem value="macos" label="macOS">

<Tabs>
<TabItem value="homebrew" label="Homebrew" default>

```bash
brew install NLipatov/tungo/tungo
```

</TabItem>
<TabItem value="arm64" label="手動（Apple Silicon）">

```bash
curl -fL -o tungo https://github.com/NLipatov/TunGo/releases/latest/download/tungo-darwin-arm64 && \
sudo mkdir -p /usr/local/bin && \
chmod +x tungo && \
sudo mv tungo /usr/local/bin/
```

</TabItem>
<TabItem value="amd64" label="手動（Intel）">

```bash
curl -fL -o tungo https://github.com/NLipatov/TunGo/releases/latest/download/tungo-darwin-amd64 && \
sudo mkdir -p /usr/local/bin && \
chmod +x tungo && \
sudo mv tungo /usr/local/bin/
```

</TabItem>
</Tabs>

</TabItem>
<TabItem value="windows" label="Windows">

[リリースページ](https://github.com/NLipatov/TunGo/releases/latest)から、お使いの PC のアーキテクチャに対応する `.exe` インストーラーをダウンロードして実行してください。

</TabItem>
</Tabs>
