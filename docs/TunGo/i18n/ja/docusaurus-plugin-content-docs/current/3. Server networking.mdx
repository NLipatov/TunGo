# サーバーのネットワークとポート

既定のポートは **UDP：9090**、**TCP：8080**、**WebSocket：1010** です。初期状態では UDP のみ有効です。

クライアントから使用するポートに接続できるよう、サーバー側とホスティング事業者側のファイアウォールで通信を許可してください。

## プロトコルやポートを変更する

有効にするプロトコルとポートは `/etc/tungo/server_configuration.json` で設定します。サーバーのポートを変更したら、クライアントの設定も同じポートに変更してください。その後、サーバーとクライアントを再起動します。
